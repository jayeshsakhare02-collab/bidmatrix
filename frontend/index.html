The BidMatrix Mechanism

Live bidding, automatic closing, and mathematically fair second-price settlement.

Step 1

Pick a bidder

Choose an existing bidder from the header, or register a new one. Each bidder keeps a full bid history.

Step 2

Place a bid

Bid with one click or enter a custom amount. Every bid must beat the current highest and is inserted into the auction's Max-BST.

Step 3

Timer expires

A background thread watches the Min-BST of closing times and closes each auction the second its timer runs out.

Step 4

Vickrey settlement

The rightmost node wins. The winner pays the second-highest bid, read from the in-order predecessor in the tree.

Frequently Asked Questions

What is a Vickrey second-price auction and why use it?

The highest bidder wins but pays the second-highest bid. Because your own bid never sets your price, the best strategy is simply to bid your true valuation — no sniping games.

What if only one person bids?

With a single bidder there is no second-highest bid, so the winner pays their own bid. If nobody bids, the auction closes with no winner.

Which data structures power the backend?

A Max-BST per auction for bids, a global Min-BST for closing times, a FIFO queue for notifications, and a hand-written linked list for each user's bid history, all implemented by hand in C++.

How big does each new bid have to be?

Any amount above the current highest bid (or above the starting price for the first bid). The one-click button uses a sensible step based on the current price.
